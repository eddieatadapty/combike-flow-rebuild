# Combike Growth Audit

**Live → https://eddieatadapty.github.io/combike-flow-rebuild/**

Five ideas to turn more Combike users into subscribers, each built into a clickable version of Combike's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Say their goal back before the paywall | +10–20% CR to purchase |
| 02 | Let them set a goal on your own speedometer | +5–15% CR to purchase |
| 03 | Make $17.99 a year read as $1.50 a month | +10–15% ARPU |
| 04 | Show 3,200 reviews before the price | +5–15% CR to purchase |
| 05 | Offer lifetime to people who close it | +5–10% ARPU |

Every price, rating and feature comes from Combike's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Combike. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
